# Ecuaciones de Poisson y de Laplace

```math
\vec E=-\frac{\partial V}{\partial x}\hat i-\frac{\partial V}{\partial y}\hat j-\frac{\partial V}{\partial z}\hat k=-\vec\nabla V
```

Ecuación diferencial de Gauss

```math
\vec\nabla\cdot\vec E=\frac\rho{\varepsilon_0}
```

```math
\vec\nabla\cdot\left(-\vec\nabla V\right)=\frac\rho{\varepsilon_0}\Rightarrow\vec\nabla\cdot\left(\vec\nabla V\right)=-\frac\rho{\varepsilon_0}
```

```math
\vec\nabla\cdot\left(\vec\nabla V\right)=\nabla^2V=\frac{\partial^2V}{\partial x^2}+\frac{\partial^2V}{\partial y^2}+\frac{\partial^2V}{\partial z^2}
```

Ecuación de Poisson

```math
\nabla^2V=-\frac\rho{\varepsilon_0}
```

Si en la zona de trabajo la densidad de carga es nula, queda:

```math
\nabla^2V=\frac{\partial^2V}{\partial x^2}+\frac{\partial^2V}{\partial y^2}+\frac{\partial^2V}{\partial z^2}=0
```
