La capacidad calorífica C de una muestra de masa m de una sustancia particular
se define como la energía necesaria para elevar la temperatura de la muestra en
un grado centígrado(1ºC).

Si la energía Q produce un cambio de temperatura $`\Delta T`$ se cumple:

```math
C=\frac Q{\Delta T}\quad\Rightarrow\quad Q=C\Delta T
```

El calor específico c de una sustancia se define como la capacidad calorífica
por unidad de masa.

Si transferimos una energía Q que produce un cambio de temperatura $`\Delta T`$
en una muestra de masa m, calor específico de dicha sustancia es:

```math
c=\frac Cm=\frac Q{m\Delta T}\quad\Rightarrow\quad Q=cm\Delta T
```
