Intensidad para N rendijas

```math
I=I_0\left(\frac{\mathop{\mathrm{sen}}\nolimits(\beta/2)}{(\beta/2)}\right)^2
\left(\frac{\mathop{\mathrm{sen}}\nolimits N(\phi/2)}{\mathop{\mathrm{sen}}\nolimits(\phi/2)}\right)^2
```

Término de difracción

```math
\left(\frac{\mathop{\mathrm{sen}}\nolimits(\beta/2)}{(\beta/2)}\right)^2
\quad\Rightarrow\quad
\beta=\pi\frac{2a}{\lambda}\mathop{\mathrm{sen}}\nolimits\theta
```

Término de interferencia

```math
\left(\frac{\mathop{\mathrm{sen}}\nolimits N(\phi/2)}{\mathop{\mathrm{sen}}\nolimits(\phi/2)}\right)^2
\quad\Rightarrow\quad
\phi=\pi\frac{2d}{\lambda}\mathop{\mathrm{sen}}\nolimits\theta
```

## Observaciones de transcripción

El original escribe «sen N(φ/2)», sin paréntesis que incluyan N en el argumento.
Se conserva esa disposición y no se interpreta como potencia. Esta diapositiva
aparece después de «Fin tema13».
